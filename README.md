
# KMUTNB Shop

ระบบร้านค้าสวัสดิการมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ

## รายวิชา
Web Framework

## เกี่ยวกับโครงการ
KMUTNB Shop เป็นเว็บไซต์สำหรับค้นหาและดูรายละเอียดสินค้าของร้านค้าสวัสดิการมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ ช่วยอำนวยความสะดวกให้นักศึกษา บุคลากร และบุคคลทั่วไป สามารถเข้าถึงข้อมูลสินค้าได้ง่ายขึ้น

ผู้ใช้งานสามารถเรียกดูรายการสินค้า ค้นหาสินค้า ดูรายละเอียดและราคา รวมถึงตรวจสอบสถานะการจองสินค้าได้ผ่านเว็บไซต์

## คุณสมบัติของระบบ
- แสดงรายการสินค้า
- แสดงรายละเอียดสินค้าและราคา
- ค้นหาสินค้าจากชื่อสินค้า
- แสดงจำนวนสินค้าคงเหลือ
- ตรวจสอบสถานะการจองสินค้า
- รองรับการใช้งานบนคอมพิวเตอร์และโทรศัพท์มือถือ
- มีระบบเข้าสู่ระบบสำหรับเจ้าหน้าที่

## เทคโนโลยีที่ใช้ (Technologies Used)

### Frontend
- **HTML** — ใช้สร้างโครงสร้างหน้าเว็บไซต์
- **CSS** — ใช้กำหนดรูปแบบและการแสดงผลของเว็บไซต์
- **JavaScript** — ใช้เพิ่มการทำงานแบบโต้ตอบบนหน้าเว็บไซต์
- **Tailwind CSS** — ใช้จัดรูปแบบและออกแบบส่วนติดต่อผู้ใช้ (UI)
- **HTMX** — ใช้อัปเดตเนื้อหาบางส่วนของหน้าเว็บโดยไม่ต้องโหลดหน้าใหม่ทั้งหมด

### Backend
- **Python** — ภาษาหลักที่ใช้พัฒนาระบบฝั่งเซิร์ฟเวอร์
- **Django** — Web Framework สำหรับจัดการการทำงานของระบบ การประมวลผลข้อมูล และการเชื่อมต่อกับฐานข้อมูล

### Database
- **Supabase** — แพลตฟอร์มที่ให้บริการฐานข้อมูลและบริการจัดการข้อมูล
- **PostgreSQL** — ระบบจัดการฐานข้อมูลเชิงสัมพันธ์สำหรับจัดเก็บข้อมูลของระบบ

### File Storage
- **Supabase Storage** — ใช้จัดเก็บและจัดการไฟล์ เช่น รูปภาพสินค้า

### Deployment
- **Render** — ใช้ Deploy เว็บไซต์เพื่อให้ผู้ใช้งานสามารถเข้าถึงระบบผ่านอินเทอร์เน็ตได้
