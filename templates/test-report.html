7.1 ขอบเขตและวิธีทดสอบ

ทดสอบระบบแบบ System Testing ครอบคลุม CRUD, Authentication, Authorization, Validation, Error Handling, Search and Filter และ Security รวมถึง workflow การจองและการจัดการสต็อก

เครื่องมือ: Django TestCase, Django Test Client, PostgreSQL, Python 3.13.12

คำสั่งที่ใช้: python manage.py test --keepdb --verbosity 2

ผลการรันจริงจากโค้ดปัจจุบัน: Ran 54 tests in 273.209s — OK (Passed 54, Failed 0, Error 0, Not Run 0)

7.2 Coverage ครบ 8 ด้าน

  • CRUD: create, read, update และ delete สินค้า หมวดหมู่ จุดจำหน่าย สต็อก บัญชี และ reservation
  • Authentication: login สำเร็จ/ผิดพลาด และ logout
  • Authorization: anonymous, staff และ admin รวมถึงการจำกัด stock ตาม location
  • Validation: ราคา category รหัสนักศึกษา quantity และ stock ติดลบ/ซ้ำ
  • Error Handling: location ผิด, reservation หมดอายุ และฐานข้อมูลปฏิเสธค่าติดลบ
  • Search and Filter: สินค้า staff stock reservation category และ location
  • Security: CSRF, ปลอม ID ลบข้อมูล และแก้ stock ข้าม location
  • Performance: query budget ของ reservation list ไม่เกิน 10 queries และ product detail ไม่เกิน 12 queries

Trigger คืน stock ที่ตรวจแล้ว: สร้าง reservation, status lookup, reservation list, dashboard และ product detail — ทั้ง 5 จุดผ่าน test เฉพาะทาง
