7.1 วัตถุประสงค์และขอบเขตการทดสอบ

ทดสอบการทำงานสำคัญของระบบร้านค้า ได้แก่ การจัดการสินค้า หมวดหมู่ จุดจำหน่าย บัญชีผู้ใช้ การเข้าสู่ระบบ สิทธิ์การใช้งาน และกระบวนการจองสินค้า ตั้งแต่การสร้าง แสดง แก้ไข ลบ ตรวจสอบข้อมูล ไปจนถึงการจัดการข้อผิดพลาดและสต็อกคงเหลือ

7.2 สภาพแวดล้อมและเครื่องมือที่ใช้ทดสอบ

Django 6.1.1Python 3.13.12PostgreSQLDjango TestCaseDjango Test Client

คำสั่งที่ใช้: python manage.py test --keepdb

ผลการตรวจสอบระบบเบื้องต้นด้วย manage.py check ไม่พบปัญหา ส่วน warning เรื่องโฟลเดอร์ staticfiles ไม่มี ไม่กระทบผลการทดสอบระบบ

7.3 การใช้ AI ช่วยสร้าง Test Cases

ใช้ AI ช่วยวิเคราะห์ models, forms, views, URLs และ permission ของระบบ แล้วสร้างกรณีทดสอบตามเส้นทางการทำงานจริง โดยทุกกรณีมี docstring/comment ใน source code อธิบายวัตถุประสงค์และผลลัพธ์ที่คาดหวัง จากนั้นรันกับฐานข้อมูลทดสอบจริงของ Django เพื่อยืนยันผล

7.4 หลักเกณฑ์การออกแบบกรณีทดสอบ

  • ครอบคลุมข้อมูลถูกต้อง ข้อมูลว่าง ข้อมูลผิดรูปแบบ และค่าที่อยู่นอกขอบเขต
  • ตรวจสอบทั้งผลลัพธ์ที่แสดง สถานะ HTTP การ redirect ฐานข้อมูล และสต็อก
  • แยกทดสอบ Authentication และ Authorization ตามบทบาท Admin, Staff และผู้ใช้ที่ยังไม่เข้าสู่ระบบ
  • ใช้ข้อมูลทดสอบแยกจากข้อมูลจริง และให้แต่ละเคสทำงานซ้ำได้
